# Possession experiments

## Goal and limits

Predict the possession team or dead-ball state for each frame. No method here has been demonstrated to be best on the full match. The public five-minute labels may be used to check the pipeline but not to select or tune a method. Use labelled data from other matches for independent assessment.

## What we learned

Most missing tracking is in long gaps, including breaks and periods outside play. Gaps of 5–30 seconds cover about 37,240 frames; longer gaps cover about 48,380. These numbers include frames outside the match and must not be interpreted as missing live play.

Set-piece tags are uncertain windows, not precise whistle times: the 53 throw-in, corner, goal-kick and free-kick tags span 35 seconds each, and six kickoff tags span five seconds each. Tagging them all as dead ball would be unjustified. Many restarts do not identify the team.

## Current experiments

- `first_solution.py`: fills a missing-ball gap of at most five seconds if the closest-player team before and after it agrees, then uses the baseline smoothing. It is an assumption, not a guarantee of uninterrupted play.
- `tag_solution.py`: builds on the above. It additionally fills a gap of up to 30 seconds if the same team appears at both ends and an attacking-phase tag supports that team throughout, with no opposing phase or set-piece window overlapping. Set-piece veto applies to this additional fill only: the earlier short-gap rule and smoothing can still bridge stoppages. Tags are automated, imperfect and represent phases rather than precise possession.

Both outputs passed the format validator. The tag-based output was regenerated byte-for-byte in this environment. Format validity and reproducibility do not establish accuracy.

## Artificial missing-data check

`gap_diagnostic.py` hides observed tracking data in 100 well-observed windows at each gap length, and asks how often each method agrees with the hidden nearest-player team. It uses a fixed random seed and no possession labels. The result is **not possession accuracy**: nearest player is a noisy proxy, naturally missing ball data is not random, and artificial windows may not resemble real gaps. This diagnostic cannot establish an improvement in spellF1 or select a winner.

| Gap length | Baseline smoothing | Short-gap rule | Tag-supported rule |
| --- | ---: | ---: | ---: |
| 1 second | 82.8% | 85.9% | 85.9% |
| 3 seconds | 76.8% | 80.1% | 80.1% |
| 6 seconds | 51.3% | 51.3% | 53.7% |

## Next direction

Test methods against independently labelled other matches, using separate matches for development and testing. Investigate team-level distances and sustained evidence before changing possession, plus a separate stoppage model using pitch boundaries and restart evidence. Boundary measurements and automatic tags are noisy; exact stoppage times cannot be inferred from tags alone. Record assumptions and avoid fitting the public match labels. The match data is separately licensed and must not be published.

## Re-run

From this project directory:

```bash
export MTAH_DATA_DIR="/path/to/match_data"
PYTHON="python"
"$PYTHON" tag_solution.py
"$PYTHON" gap_diagnostic.py
"$PYTHON" evaluation/validate_submission.py evaluation/results/tag_solution.csv
```

Set `MTAH_DATA_DIR` to the directory containing the `tactical` subfolder, as described in `DATA.md`. The verified environment used Python 3.13.18, NumPy 2.5.4 and pandas 3.1.1; `requirements-tested.txt` records the package versions. The submission still needs a public reproducible repository and technical document.
